INSTALARE ÎN CHROME

Gata de utilizare în sub 60 de secunde

Nu necesită conturi, nu cere permisiuni intruzive și rulează direct pe profilul tău de browser.

1

Descarcă proiectul

Clonează depozitul GitHub sau descarcă arhiva ZIP pe calculatorul tău.

git clone https://github.com/alexandru-radutoma/diacritice.git
2

Deschide Modul Dezvoltator

În Google Chrome, deschide pagina de extensii și activează comutatorul din dreapta-sus.

chrome://extensions
3

Încarcă dosarul

Apasă pe butonul „Încarcă extensia despachetată” și selectează folderul descărcat.

Gata! Extensia este activă pe loc. 🎉
